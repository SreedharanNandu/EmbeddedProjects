The project demonstrates LIN (9600kbps) as slave to receive distance data from 2 ultrasonic sensors, produces audiable buzzer based on distance.
The project uses hardwired push switch to turn ON/OFF and LED inidication.
Sensor LIN Id:- 0x14 and 8 byte data 
Transceiver used :- TJA1027
