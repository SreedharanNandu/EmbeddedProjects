The project demonstrates LIN (9600kbps) as slave to receive LED indication ON/OFF from master .
The project also configures slave to transmit read push switch to indicate user input.
Switch LIN Id:- 0x01,0x02 and 1 byte data 
Transceiver used :- TJA1027
