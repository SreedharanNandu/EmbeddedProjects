The project demonstrates LIN (9600kbps) first channel as slave to receive distance data from 2 ultrasonic sensors, produces audiable buzzer based on distance.
The project also configures LIN second channel as master to read push switch to turn ON/OFF the system and indicate LED on another LIN slave module .
Sensor LIN Id:- 0x14 and 8 byte data 
Switch LIN Id:- 0x01,0x02 and 1 byte data 
Transceiver used :- TJA1027
