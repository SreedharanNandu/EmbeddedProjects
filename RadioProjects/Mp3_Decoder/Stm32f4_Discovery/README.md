The projects here demonstrates the capability of cortex M4F micro to decode MP3 on flash drive (FAT32,FAT16 only) 

For build,install use 5.4 2016q3 GCC compiler and set path in folder options.

Note that KEIL Uvision project uses 32K binary lock for compiler and debugger, so use STM32 Cube IDE empty project to debug.
Note: These projects are free to refer/clone/modify for hobby/educational purpose and strictly not for commercial/business.
